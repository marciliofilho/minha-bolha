# Intro Global

Coloque aqui o vídeo de abertura usado para os demais idiomas:

```text
assets/global/intro.webm
```

Formato recomendado: WebM VP9 com canal alpha (`yuva420p`) e áudio Opus, igual ao arquivo `assets/pt-BR/intro.webm`.

Enquanto este arquivo não existir, o app abre sem animação quando o idioma efetivo não for Português (Brasil). O vídeo PT-BR fica em `assets/pt-BR/intro.webm` e é usado apenas para `pt-BR`.
